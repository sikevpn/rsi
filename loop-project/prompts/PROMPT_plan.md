# 规划模式（plan）

你处于 **plan** 模式。目标：把一个需求拆成可独立验证的小任务，写进
`IMPLEMENTATION_PLAN.md` 的复选框列表。

{task}

## 拆解规则

1. 每个任务必须能被一条客观命令验证（test/lint/typecheck/build），否则不要写进来。
2. 每个任务应在一轮 fresh context 内可完成；做不完的继续拆。
3. 任务带稳定 ID：`- [ ] (T1) ...`。ID 一旦分配不要重排。
4. 不确定的地方写成显式假设，不要藏在任务描述里。
5. 不写实现代码。本模式只产出计划。
